Installing

  1. Download the ISO (the CD), once.
  2. Power on: the browser's disk is empty, so the machine asks for the CD - choose the ISO.
  3. In rio: inst/start. The install is 9front's, except that copydist copies the base system, the tools and the source with its git, not the whole system built. Its reboot boots the installed system from the disk.
  4. Build the rest on the machine: bind -ac /dist/9front /; cd /sys/src; mk install

To install anew: BIOS, "Boot once from CD".
